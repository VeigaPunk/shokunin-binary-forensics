             コーディングエージェントとのリバースエンジニアリング 
             ソフトウェアの 仕組みを知ろう。 
             
              アプリ、ゲーム、ウェブサイトについてコーディングエージェントに質問してみましょう。REA は、答えの根拠となるコードを調べるためのツールを提供します。

               例を見る ↓

                 ブログ →  — 手法とソフトウェア再実装の記録。

               このプロンプトをコーディングエージェントに貼り付けてください：

             仕組み 
           
           
            リバースエンジニアリングとは、プログラムそのものを調べてソフトウェアの仕組みを理解することです。REA を使えば、エージェントがコードをたどり、機能を説明し、その再実装を手伝えます。
           
           
             
               一つの機能について質問する 
               エージェントにプログラムやページを渡し、質問します。 
             
             
               プログラムを調べる 
               REA はコード、参照関係、実行時の観測結果を返します。 
             
             
               理解してから変更を試す 
               
                エージェントは調査結果をもとに機能を説明したり、再実装したりします。

             例01•Chromeの恐竜ゲーム 
             恐竜はなぜ速くなる？ 
           
           
            走り続けるとゲームの速度が上がります。速度を調節できる形で再実装するには、まず速度が変わる仕組みを調べます。
           
           
             
               1. 速度について質問する 
               
                 
                           質問の例 · 恐竜ゲーム 
                   
                    コピー
                   
                 
                 
                   ›  この恐竜のゲームを検査するためにREAを使用してください。 なぜそれは速くなるのですか？ 速度ルールを表示し、調整可能な速度で小さなバージョンを構築します。   
                 
               
               2. 速度のルールを見つける 
               
                REA を使うと、エージェントが実行中のゲームのコードを読めます。速度は 6 から始まり、13 未満の間は更新ごとに少しずつ上がります。
               
             
             
               3. 作ったゲームで遊ぶ 
               
                下のミニゲームにこのルールを再現し、速度スライダーを加えました。スタートを押して、自分の速度を選んでみましょう。
               
               
                 
                   
                     
                     
                      6 → 10 → 13
                     
                   
                    
                 
                 
                   
                     
                      スタート
                     
                     ジャンプ ↑ 
                     リスタート 
                   
                   速度  6.0   
                     回復された加速ルールを使用する 
                 
                 
                  元のルール：6から開始し、13に向かって増加します。
                 
                 
                  スライダーを動かして独自の速度を設定します。 スペースまたはジャンプはサボテンをクリアします。
                 
                  
                    遊ぶには JavaScript を有効にしてください。ルールを読んだり、下のソースコードを開いたりすることはできます。
                    
               
               スピードラボを開く→ 
             
           
           
             
              スクリプト、チェック、および分析を試す方法を参照してください
             
             
              検査対象:  wayouのChromium派生ブラウザ版 .
             
             
               
                 REA·ロード  index.js  *選択した行 
               
                if (this.currentSpeed  this.currentSpeed += this.config.ACCELERATION; 
}  
             
             
              6時からスタート。 追加 0.001 速度は以下のとおりですが、衝突のない各更新 13.
             
             
               各部分が何をするか 
               
                 
                   01*REA   実行中のゲームのスクリプトを読む  実際のコードと設定をエージェントに返します。 
                 
                 
                   02*あなたの代理店  ルールを再構築し、コントロールを追加します  スピードスライダーで小さなゲームで回収された加速を使用してください。 
                 
                 
                   03*あなた  スピードとプレイを変更します  元の加速を試してから、自分のペースを選択してください。 
                 
               
             
             
              REAは、ローカルデバッグ接続を介してHTTP browser editionを検査し、ロードされたものを返しました  index.js 、そのソースとダイジェストを含みます。
             
             
               
                 検査されたスクリプトから選択された設定 
               
                ACCELERATION: 0.001,
MAX_SPEED: 13,
SPEED: 6  
             
             
              私たちは、障害物や自動スケジューリングを無効にして、制御されたブラウザチェックで元のゲームの更新機能を呼びました。 4,000回の更新後の速度は10.0、10,000回の更新後は13.0で、小数点以下1桁に四捨五入されていました。
             
             
              新しいミニゲームは、その速度ルールを保持します。 その描画、ジャンプ、および衝突コードは、小さな教育の実装です。  ラボを開く  新しいコードを表示し、同じ速度チェックを実行するには。
             
             
              ターゲットを自分で検査するには、次の手順に従います  ブラウザ接続手順  を使用して  恐竜のページ . エージェントにページURLとローカルデバッグエンドポイントを指定し、上記のプロンプトをコピーします。

             例02•Windows計算機 
             電卓の % ボタンを再現する。 
           
           
            % ボタンは + の後と × の後で動作が異なります。二つのルールを調べ、小さな電卓で試しましょう。
           
           
             
               1. % ボタンについて質問する 
               
                 
                           質問の例 · 電卓 
                   
                    コピー
                   
                 
                 
                   ›  REAを使用して、Windows計算機の%ボタンを検査します。 +と×の後にルールを回復し、両方を使用する小さな電卓を作成します。   
                 
               
               2. 二つのルールを見つける 
               
                REA は、エージェントが % ボタンのコードを読むのを助けます。このコードは二つのルールを使います。
               
               
                 
                   と+ 
                   
                     最初の数の10％を取ります。  10% of 200 = 20 → 200 + 20 = 220 
                   
                 
                 
                   ×付き 
                   
                     10％を0.1に変えます。  200 × 0.1 = 20 
                   
                 
               
             
             
               3. % ボタンを試す 
               
                下に二つのルールを再現しました。+ または × を選び、% を押してから = を押します。
               
               
                 
                   
                     200 + 10% 
                   
                   
                     200 × 10% 
                   
                 
                 
                   200 + 
                   20 
                 
                 
                   
                    %
                   
                   
                    =
                   
                   
                    リセット
                   
                 
                 
                  10%の200=20. 次に、200+20=220。
                 
                 
                  検査されたパーセンテージルールのインタラクティブなイラスト。
                 
               
             
           
           
             実際のコードと答えがどのようにチェックされたかを参照してください 
             
              この例では,  previous = 200  と  current = 10 .
             
             
               
                 %ハンドラーの読み取り可能な要約 
               
                if (operation == multiply || operation == divide) {
  percent = current / 100;
} else {
   percent = current * previous / 100; 
}

                   02*REAはライブラリを読み込みます  %ハンドラーのコードを返します  関数は演算子をチェックし、定数を使用します  100 . 
                 
                 
                   03*あなたのエージェントはそれを解釈します  ルールの説明と再現  ブランチをMicrosoftのソースと照合してから、上記の+と×を試してください。
