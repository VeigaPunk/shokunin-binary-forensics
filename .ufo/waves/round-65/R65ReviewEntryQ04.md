Entry line 144:

But entry line 4 (`verified-at:`) and line 121 (§Comparison) state a tool claim:

That is CPython 3.14.8 exercising `generator.py`, scored on its own output (the regenerated bytes). Under QUALITY.md:16 that claim is **compliant** — tool (CPython), version (3.14.8), function (`generator.py`) and its own explicit output are all named — so the `pass` decision stands, but the stated basis is false as written. Host check: `python3 --version` → `Python 3.14.8`, and `truth.json` `build_recipe.python_version` = `3.14.8`, so the version pin is the real one. Recommended row text: "manual stdlib byte analysis labeled manual (items 1–10); one scoped tool claim (`verified-at:`, §Comparison) names CPython 3.14.8 + `generator.py` and scores its own byte-for-byte output." Secondary imprecision: "the only tool named is Python itself" ignores `struct` named at line 11 and `generator.py` named at line 121.
