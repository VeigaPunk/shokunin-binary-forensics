## The 3 most important lessons / gains

1. **"Recognized framing" is no longer the same as "recoverable."** The dcz note reframes a Zstandard skippable frame from an opaque span to preserve into a named external dependency (a 32-byte SHA-256 of a dictionary that is not in the artifact). The working rule it adds: record the advertised dictionary hash and whether matching bytes were kept, and never treat header recognition as standalone recoverability or the hash as producer authentication. This is a depth gain on the compression/archive notes the lane already had.

2. **Field width does not tell you field role.** Two notes make the same lesson concrete in different formats. In TIFF, a six-byte payload is a pointer in classic TIFF but inline in BigTIFF (4-byte vs 8-byte threshold), so format, datatype and count must be settled before reading the value field as an address. In Wasm, `i64.load` names a result type, not an address width; memory64 has to come from the memory's declared address type, not from 64-bit arithmetic. Together they are a reusable calibration guard against width-based inference.

3. **Coverage gained: interpretation dependencies, with a stated denominator.** The container-interpretation note does a bounded novelty check (383 curation artifacts plus 16 existing considerthese files; Parquet and Avro absent, pcapng only mentioned in passing) and then adds four formats where meaning depends on state outside the bytes: pcapng section/interface state, Protobuf schema binding, Avro writer/reader schema and fingerprints, Parquet footer vs page coverage. Each case has falsifying controls, size and time caps, a held-out second-reviewer fixture, and a stop rule after two iterations with no narrower claim. It is plan-only (every exercise is marked unperformed), so this is coverage of the question space, not a new capability row; capabilities stay at five and K at 14/15.
