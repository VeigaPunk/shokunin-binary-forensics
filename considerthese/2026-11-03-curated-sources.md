## 1. LLVM yaml2obj object-description reference

- **Why it fits:** Describes a textual representation of object-file structures, with COFF headers, sections and symbols. It is useful reading for recognizing the exact inputs behind a minimal, explainable binary fixture rather than treating opaque fixture bytes as self-authenticating.
- **Reading and proposed later use:** Read COFF syntax against the lane’s existing PE-format sources. After hyaku, consider a design-only, field-to-byte worksheet for a harmless synthetic object, preserving expected observations separately from tool outputs.
- **Limits:** This is a producer format, not the normative PE specification or proof that generated bytes are valid. No generation, execution, mutation campaign or harness change is authorized here. Keep the proposed use limited to domain artifact interpretation.
- **License:** Apache-2.0 WITH LLVM-exception (LLVM project documentation source). [License evidence](https://raw.githubusercontent.com/llvm/llvm-project/main/LICENSE.TXT)
- **Duplicate check:** LLVM PDB documentation is already present in the lane; this is a distinct object-description surface. No yaml2obj link or mention was found. It must not become ownership of generic harness/evidence auditing.

## 2. diffoscope
- **Type and source:** Maintained repository — [primary source](https://salsa.debian.org/reproducible-builds/diffoscope)
- **Version / maintenance:** Official project page lists release 336 dated 2026-10-30; no repository commit pinned. Official site showed releases 334–336 in October 2026 and linked the Salsa repository; repository landing page opened successfully but its detailed tree did not render. [Evidence](https://diffoscope.org/)
- **Why it fits:** Compares structured contents of archives and binary artifacts, including several formats in this province. Its layered reports can help separate packaging metadata changes from payload changes in authorized before/after artifacts.
- **Reading and proposed later use:** Start with the official examples and format list. After hyaku, consider a report-only review plan for two owned artifacts, preserving both original hashes and the exact comparator/helper versions.
- **Limits:** Recursive unpacking and external helpers enlarge the parser attack surface; later runs need isolation and resource limits. Missing helpers can reduce comparisons to less informative output. A diff is not a proof of semantic equivalence or maliciousness. Do not upload private artifacts to its online demo.
- **License:** GPL-3.0-or-later; external helper tools have separate licenses. [License evidence](https://diffoscope.org/#license)
- **Duplicate check:** No diffoscope source family found in the supplied inventory/context. Existing reproducible-build definitions and binary diff tools are related; this adds structured cross-format package comparison.
